# NovelNest 图书导入功能说明

## 功能概述

NovelNest 提供了完整的图书导入功能，支持多种文件格式和导入方式，让您轻松管理您的电子书收藏。

## 支持的文件格式

- **TXT** - 纯文本文件
- **EPUB** - 标准电子书格式
- **PDF** - PDF文档
- **MOBI** - Kindle格式（计划支持）
- **AZW3** - Kindle格式（计划支持）

## 导入方式

### 1. 单个文件导入
- 点击"导入图书"按钮
- 选择"导入单个文件"
- 在文件选择器中选择要导入的电子书文件
- 系统会自动解析文件信息并添加到图书库

### 2. 批量文件夹导入
- 点击"导入图书"按钮
- 选择"批量导入文件夹"
- 选择包含电子书文件的文件夹
- 系统会递归扫描文件夹中的所有支持格式文件
- 在预览界面中确认要导入的文件
- 支持按格式筛选和批量选择

### 3. 拖拽导入（开发中）
- 直接将文件或文件夹拖拽到导入区域
- 系统会自动识别文件格式并开始导入

## 导入设置

### 文件格式设置
- 可以启用或禁用特定文件格式的支持
- 自定义每种格式的处理方式

### 导入选项
- **跳过已存在的文件** - 避免重复导入相同文件
- **自动提取元数据** - 自动从文件中提取书名、作者等信息
- **创建备份** - 在导入前创建原文件备份

### 文件命名规则
- **保持原文件名** - 使用原始文件名
- **使用书名** - 使用提取的书名作为文件名
- **书名_作者** - 组合书名和作者信息
- **作者_书名** - 以作者开头的命名方式

## 元数据提取

### TXT文件
- 自动从文件名提取书名
- 尝试从文件前几行提取作者信息
- 支持常见的作者标识格式（如"作者："、"Author:"等）

### EPUB文件
- 从EPUB元数据中提取完整的书籍信息
- 包括书名、作者、出版信息等

### PDF文件
- 从PDF元数据中提取基本信息
- 支持标题和作者信息提取

## 导入进度显示

- 实时显示导入进度
- 显示当前正在处理的文件
- 显示成功、失败和跳过的文件统计
- 详细的错误信息和处理结果

## 错误处理

### 常见错误及解决方案

1. **文件格式不支持**
   - 确认文件格式在支持列表中
   - 检查文件扩展名是否正确

2. **文件损坏或无法读取**
   - 检查文件是否完整
   - 尝试用其他软件打开文件验证

3. **权限不足**
   - 确保应用有读取文件的权限
   - 检查文件是否被其他程序占用

4. **磁盘空间不足**
   - 清理磁盘空间
   - 选择其他存储位置

## 使用技巧

1. **批量导入优化**
   - 将同类型文件放在同一文件夹中
   - 使用预览功能确认导入列表
   - 合理设置跳过选项避免重复

2. **元数据管理**
   - 导入后可以在图书详情中编辑元数据
   - 建议在导入前整理好文件名和文件夹结构

3. **性能优化**
   - 大量文件导入时建议分批进行
   - 关闭不必要的后台程序释放系统资源

## 故障排除

如果遇到导入问题，请按以下步骤排查：

1. 检查文件格式和完整性
2. 确认应用权限设置
3. 查看错误日志信息
4. 尝试单个文件导入测试
5. 重启应用后重试

## 技术实现

### 前端组件
- `BookImporter.vue` - 主要导入界面组件
- `useToast.js` - 消息提示管理
- `Modal.vue` - 模态框组件
- `Loading.vue` - 加载状态组件

### 后端命令
- `import_book` - 单个文件导入
- `import_folder` - 文件夹批量导入
- `scan_folder_for_books` - 扫描文件夹
- `batch_import_books` - 批量导入处理
- `get_file_info` - 获取文件信息
- `check_book_exists` - 检查文件是否已存在

### 数据模型
- `Book` - 图书数据模型
- `ImportResult` - 导入结果模型
- `BatchImportResult` - 批量导入结果模型
- `FileInfo` - 文件信息模型
